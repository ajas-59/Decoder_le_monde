# Decoder le monde : Apprendre le Python & l’IA par projets

Projet Pépite EdTech : pour devenir étudiant entrepreneur

*Une plateforme pédagogique interactive et inclusive*

---

## 🚀 Objectif du projet

Ce projet a pour ambition de rendre l’apprentissage du **code** et de **l’intelligence artificielle** accessible à **tous**, en particulier aux **étudiants** débutants issus de filières non techniques.

Il s’appuie sur une **pédagogie 100 % par projet**, ludique, progressive et personnalisable.  
Chaque module propose un mini-projet concret à réaliser, autour de thèmes motivants comme les séries, la musique ou l’actualité.

---

## 🧩 Projets inclus

| Niveau       | Projet                           | Description                                           |
|--------------|----------------------------------|-------------------------------------------------------|
| Débutant     |  **Devine ta série du moment** | Logique conditionnelle et assistant personnalisé      |
| Intermédiaire|  **Recommande une série**      | Traitement de texte (TF-IDF, similarité cosinus)     |
| Intermédiaire|  **Détection de fake news**     | NLP, classification texte, réflexion éthique         |
| Avancé       |  **Recommender musical**        | KNN, distances, système de recommandation + interface|

 **Chaque dossier contient :**
- `notebook.ipynb` : le code du projet
- `data/` : les données utilisées
- `README_project.md` : la fiche pédagogique du projet
- `app.py` *(optionnel)* : une interface avec Gradio ou Streamlit

---

## 🛠 Compétences développées

-  **Programmation Python** : variables, conditions, fonctions, listes
-  **Manipulation de données** : `pandas`, `matplotlib`, nettoyage
-  **Machine learning** : classification, recommandation, KNN
-  **NLP** : TF-IDF, vectorisation, analyse de texte
-  **App interactives** : interface utilisateur avec `Gradio`
-  **Éthique de l’IA** : biais, transparence, usages responsables
